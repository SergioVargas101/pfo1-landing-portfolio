# PFO1 - Landing de Portfolio Personal

Landing personal realizada para la materia **Desarrollo de Sistemas Web - Front End**.

El objetivo de esta PFO fue desarrollar una pagina utilizando HTML y CSS para presentar mi perfil, mis habilidades, objetivos y una forma de contacto.

## Decisiones de diseño

Para la landing elegi un diseño simple y claro.

En una primera etapa utilice tonos azules y luego modifique la paleta utilizando violeta, tonos oscuros y fondos claros para darle una apariencia mas relacionada con tecnologia y desarrollo web.

La pagina se divide en:

- Inicio
- Sobre mi
- Habilidades
- Objetivos
- Contacto


### Flexbox

Utilice Flexbox para organizar el menu de navegacion y la presentacion principal.

Esta fue una de las partes que mas tuve que practicar, principalmente para comprender la orientacion y alineacion de los elementos.

### CSS Grid

Utilice CSS Grid para distribuir las tarjetas de habilidades en dos columnas.

En pantallas mas pequeñas las tarjetas pasan a mostrarse en una sola columna.

### Responsive

Utilice una media query con un ancho maximo de 768px para adaptar la pagina a dispositivos mas pequeños.

### Transiciones

Se agregaron transiciones simples en enlaces, botones y tarjetas al pasar el mouse.


## Uso de Inteligencia Artificial

Para realizar este proyecto utilice ChatGPT como herramienta de apoyo.

- **Herramienta:** ChatGPT

Ya tenia experiencia previa utilizando ChatGPT para realizar consultas relacionadas con programacion y otros trabajos.

La herramienta fue utilizada principalmente para:

- Consultar algunas propiedades y atributos de CSS.
- Revisar la estructura HTML.
- Comprender mejor Flexbox.
- Comprender mejor CSS Grid.
- Buscar alternativas para organizar los elementos.
- Detectar errores de distribucion.
- Revisar algunas buenas practicas.

Una de las dificultades durante el desarrollo fue conseguir la orientacion correcta de los elementos utilizando Flexbox.

En una de las pruebas, Flexbox se estaba aplicando sobre un contenedor incorrecto y distintas secciones aparecian una al lado de la otra. Fui revisando el HTML y el CSS hasta encontrar el problema y corregirlo.

Las sugerencias obtenidas con IA fueron probadas y modificadas en Visual Studio Code utilizando Live Server antes de incorporarlas al proyecto.
